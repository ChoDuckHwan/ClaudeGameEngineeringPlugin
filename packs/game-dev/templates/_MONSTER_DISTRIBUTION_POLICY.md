## 2. 일반 몬스터 8종 — Tier 1 분배

### 1-A. 공통 재사용 (2종, 모든 레벨)

다른 시설 어디에 가도 외형 변형으로 활용 가능한 핵심 2종:

| # | 카테고리 | 특징 |
|:---:|---|---|
| C1 | 정찰/방해 | 발견 즉시 어그로 알림, 1히트 처치, 시각/청각 단서 |
| C2 | 호기심 트랩 | 무해해 보이는 외형 → 변신 후 위협. 게임 시그니처 메카닉 |

**왜 2종**:
- 너무 많으면 테마 정체성 흐려짐
- 너무 적으면 매 레벨 새 몬스터 학습 부담
- 2종이 sweet spot — 친숙한 적 + 학습된 행동 패턴 → 새 테마 빠른 적응

### 1-B. 테마 전용 (6종, 환경 의존)

각 테마에 어울리는 6종. 환경 메카닉과 결합:

| 슬롯 | 역할 | 권장 위협 |
|:---:|---|:---:|
| T1 | 정찰/방해 (테마 특화) | ●●○○○ |
| T2 | 매복 (실내) | ●●○○○ |
| T3 | 환경형 (실외/특정 구역) | ●●○○○ |
| T4 | 돌격 (실외) | ●●●○○ |
| T5 | 돌격 (실내) | ●●●○○ |
| T6 | 호기심 트랩 (테마 특화) | ●●○○○ → ●●●○○ |

**6종 분배 원칙**:
- 정찰/방해 + 매복 + 환경 + 돌격 2종 + 호기심 트랩 = 역할 다양성
- 호기심 트랩 1-A 의 1종 + 1-B 의 1종 = 총 2종 (테마당 호기심 트랩 비율 25%)

## 3. 치프 몬스터 — Tier 2 (레벨 등급별)

치프 = **봉인 메카닉 없는 미니보스**. 영역 보스 / 환경 보스 성격.

| 의뢰 등급 | 치프 수 | 배치 |
|:---:|:---:|---|
| **Bronze** | 1종 | 시설 중반 |
| **Silver** | 2종 | 시설 중반 + 후반 분기 |
| **Gold** | 2종 | 시설 중반 + 봉인실 인접 |
| **Final (Museum/우주정거장)** | 2종 + 합체 | 클라이맥스 전 다중 인카운터 |

**치프 디자인 원칙**:
- 일반 크립보다 분명히 강함 (●●●●○)
- 봉인 단서 X — 단순 처치 또는 우회
- 환경 메카닉 결합 (예: 잠수병 단장 = 감압 변동)
- 외형/명칭 변형으로 다른 시설 재사용 가능

## 4. 보스 몬스터 — Tier 3 (레벨 등급별)

| 의뢰 등급 | 보스 수 | 인카운터 형태 |
|:---:|:---:|---|
| **Bronze** | 1종 | 시설 클리어 시 1회 |
| **Silver** | 2종 | 봉인실 + 탈출 페이즈 |
| **Gold** | 2종 | 다중 봉인 + 환경 페이즈 |
| **최종 레벨** | 3-5종 | 대미 인카운터 (보스 러시 또는 합체) |

**보스 디자인 원칙**:
- ★★★★★ 위협 (게임 메인 빌런급)
- Spirit 패턴 (봉인/약점/단서 4단계)
- 시설 컨셉 고유 (재사용 X — 각 레벨만의 보스)
- 어미 개체 (FIB-Prime) = 최종 보스로 별도 (모든 시설 결말 연결)
