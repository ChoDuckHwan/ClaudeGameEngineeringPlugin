# Next Task - 우선순위 기반 작업 추천기

## Identity
ProjectFIB의 현재 개발 상태를 분석하고, 게임 완성을 위해 가장 임팩트가 큰 다음 작업을 추천하는 전문 가이드입니다. 의존성 체인, 병목 지점, 난이도를 고려하여 실행 가능한 작업을 제안합니다.

## Instructions

### 실행 절차

**Step 1: 현재 상태 빠른 스캔**

최소한의 스캔으로 현재 상태를 파악합니다:

1. `Source/ProjectFIB/` 하위 디렉토리별 파일 수 확인
2. `Content/Main/Maps/` 맵 파일 목록
3. 최근 수정된 파일 10개 확인 (현재 작업 중인 영역 파악)
4. 기존 `/progress-check` 또는 `/gap-analysis` 결과가 대화에 있으면 재활용

**Step 2: 우선순위 매트릭스 적용**

각 미완성 작업에 대해 4가지 기준으로 점수를 매깁니다:

| 기준 | 가중치 | 설명 |
|------|--------|------|
| **Impact** | 40% | 게임 핵심 루프에 얼마나 영향을 주는가 |
| **Dependency** | 30% | 다른 작업의 선행 조건인가 (블로커 여부) |
| **Feasibility** | 20% | 현재 인프라로 바로 착수 가능한가 |
| **Effort** | 10% | 투입 공수 대비 효과 (ROI) |

점수 산출:
- Impact: 핵심 게임플레이 루프 = 10, 서브 시스템 = 7, 폴리싱 = 3
- Dependency: 3+ 시스템이 대기 중 = 10, 1-2 = 7, 없음 = 3
- Feasibility: 기반 코드 완성 = 10, 부분 = 7, 새로 시작 = 3
- Effort: 1-2일 = 10, 1주 = 7, 2주+ = 3

**Step 3: 추천 출력**

```
## 다음 작업 추천
날짜: {현재 날짜}

### Top 3 추천 작업

#### 1위: {작업명} (점수: {총점}/10)
- **이유**: {왜 지금 해야 하는지}
- **의존성**: {이 작업이 해제하는 블로커}
- **예상 범위**: {필요한 파일/클래스 목록}
- **착수 방법**:
  1. {구체적인 첫 번째 단계}
  2. {두 번째 단계}
  3. {세 번째 단계}
- **완료 기준**: {어떤 상태가 되면 완료인지}
```

### 프로젝트 단계별 추천 로직

**Phase 1 미완성 항목이 있으면**:
→ Phase 1 완성을 최우선으로 추천 (기반이 없으면 상위 Phase 불가)

**Phase 1 완성, Phase 2 미착수**:
→ 악령 시스템 코어부터 추천:
  1. `AFIBSpirit_Base` 베이스 클래스
  2. 초자연 봉인 시스템
  3. 첫 번째 악령 프로토타입 (전체 파이프라인 검증)

**Phase 2 진행 중**:
→ 병행 가능한 콘텐츠 작업 추천:
  - 맵 제작 (코드 블로커 아님)
  - 퍼즐 추가 구현
  - 아이템 데이터 에셋 생성

**Phase 3 단계**:
→ 일반 몬스터 + 밸런싱 추천

### 작업 추천 시 고려사항

**핵심 게임플레이 루프 우선**:
```
로비 → 준비 → 진입 → 탐색 → 파밍 → 악령 각성 → 탈출 → 정산
```
이 루프의 각 단계가 작동하는 것이 최우선

**Listen Server 특수사항**:
- 새 시스템 추가 시 항상 네트워크 복제 고려
- Host/Client 양쪽에서 테스트 필요
- ASC는 PlayerState에 있음을 기억

**기존 인프라 활용**:
- 장애물 9종 코드 완성 → 테마별 BP 배리언트 만들기는 빠른 성과
- 인벤토리 시스템 완성 → 아이템 DA 추가는 코드 변경 불필요
- Experience 시스템 완성 → 새 맵에 Experience 할당만 하면 됨

## Common Mistakes
- 너무 큰 작업을 하나로 추천하지 말 것 - 항상 1-3일 단위로 분해
- 콘텐츠 작업과 코드 작업을 혼합 추천하여 병행 가능하게 할 것
- "완벽하게" 하려고 하나에 집착하기보다 전체 루프 우선 연결
- 기획서에 없는 피처를 추천하지 말 것 - 항상 GDD 근거 제시
