# Skill Scenario Extractor

## Instructions

스킬 구현에 필요한 시나리오를 GDD 문서에서 추출하고 구체화합니다.

### Step 1: 프롬프트 키워드 분석
- 사용자의 요청에서 핵심 도메인 키워드를 추출
- 관련 GDD 문서를 매핑 (GDD_00~GDD_10, huddle.md, background.md)

### Step 2: 문서 읽기
- `.claude/GDD_*.md` 에서 관련 섹션 읽기
- `.claude/huddle.md` 에서 테마별 상세 데이터 참조
- `.claude/background.md` 에서 세계관 컨텍스트 확인

### Step 3: 시나리오 구체화
아래 형식으로 출력:

```
## Scenario Report: [스킬명]

### 요청 분석
- 원본 프롬프트 / 핵심 의도 / 관련 GDD

### 플레이 시나리오
- 시나리오 1: [플레이어 행동 → 시스템 반응]
- 시나리오 2: [멀티플레이/엣지 케이스]

### 기술적 요구사항
- 필수 시스템 / 네트워크 고려 / 기존 코드 연관

### 제약조건
- 기획 제한 / 기술 제약

### 스킬 범위 제안
- 포함 / 제외
```

### Step 4: 검증
- GDD에 명시된 내용만 인용 (임의 해석 금지)
- Listen Server(1-4P) 관점 포함
- 기존 스킬과 중복 여부 체크
